# HRGenius Screenshot Collection

Desktop captures use a 1440 × 900 viewport. The login collection also includes a 390 × 844 mobile capture.

## Folder structure

- `Home/` - Public homepage
- `Login/` - Desktop and mobile login pages
- `Admin Panel/` - Admin overview and module pages
- `HR Panel/` - HR Manager overview and permitted module pages
- `Employee Panel/` - Employee self-service overview and permitted pages
- `Legal/` - Privacy Policy and Terms of Use

Demo screenshots were captured from the running local application.
